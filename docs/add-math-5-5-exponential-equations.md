# Add Maths 5.5 — Solving exponential equations

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.5, pages 110–112. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh problem set that covers every type, with answers. None of the
problems are the book's. Every answer was checked by script.

## Part 1 — The beats of the notes

1. **What is new (p. 110).** Earlier courses solved exponential equations by writing
   both sides as powers of the same base. This section is for the ones where that
   cannot be done.
2. **Worked example 10.** Take logs of both sides, bring the power down with the power
   law, divide. Two parts: a plain power of x, then a linear expression in the power.
   Answers to 3 s.f.
3. **Worked example 11 (pp. 110–111).** A hidden quadratic. Substitute y for the power,
   factorise, and convert each value of y back. One value is negative, and a power of a
   positive number is never negative, so it gives no solution.
4. **Reflection (p. 112).** The exercise ends by asking students how confident they are
   converting between exponential and log form.

## Part 2 — What the exercise asks

Exercise 5.5 is on pages 111–112: eleven questions, the last three marked as challenge.

| Type | Book question | What it asks | How it climbs |
|---|---|---|---|
| A. Take logs | 1 (twelve parts) | Solve to 3 s.f. | A plain power, a multiple of x, a linear power, then a different base on each side |
| B. Split with the index laws | 2, 3 | Rewrite each term as a number times the same power, solve for the power, then x | Question 2 is guided ("show that", "hence"); question 3 is five to do |
| C. Hidden quadratic | 4, 5 | Substitute for the power | Question 4 gives the substitution; question 5 is four to do |
| D. Hidden quadratic with a shifted power | 6, 7 | Split the shifted term first, then substitute | Question 6 gives the substitution; question 7 is four to do |
| E. Hidden quadratic in a disguised base | 8 (four parts) | Spot that one base is the square of the other | 4 and 2, 16 and 4, 9 and 3, 25 and 5 |
| F. Mixed bases | 9 (challenge) | Collect powers to find the value of one combined power, then x | Two parts |
| G. Modulus equations | 10 (four parts, challenge) | Exponentials inside modulus signs, or a modulus in the power | Two of each kind |
| H. Modulus inequality | 11 (challenge) | Solve, answer in exact form | One question |

## Answers

**A.** A1 5.49. A2 1.77. A3 −0.748. A4 3.19. A5 1.30. A6 2.19. A7 1.18. A8 5.34.
A9 0.415. A10 x = 3 lg 2 ÷ (lg 5 − lg 2) = 2.27. A11 x = lg 21 ÷ lg (7/3) = 3.59.
A12 x = lg 18 ÷ lg (4/3) = 10.0. A13 x = lg (5/9) ÷ lg 75 = −0.136.

**B.** B1 3ˣ⁺² = 9 × 3ˣ and 3ˣ⁻¹ = ⅓ × 3ˣ. Then (26/3) 3ˣ = 52, so 3ˣ = 6 and
x = 1.63. B2 7(2ˣ) = 21, 2ˣ = 3, x = 1.58. B3 4.5(2ˣ) = 27, 2ˣ = 6, x = 2.58.
B4 4.4(5ˣ) = 11, 5ˣ = 2.5, x = 0.569. B5 6(3ˣ) = 10, 3ˣ = 5/3, x = 0.465.
B6 −3(4ˣ) = −24, 4ˣ = 8, x = 1.5 exactly.

**C.** C1 y² − 6y + 8 = 0, y = 2 or 4, x = 1 or 2. C2 3ˣ = 1 or 9, x = 0 or 2.
C3 5ˣ = 2 or 5, x = 0.431 or 1. C4 2ˣ = 4 (−3 rejected), x = 2.
C5 7ˣ = 5 (−1 rejected), x = 0.827. C6 3ˣ = 3 (−5 rejected), x = 1.
C7 2ˣ = −2 or −3: no solutions, because 2ˣ is always positive.

**D.** D1 u² − 12u + 27 = 0, u = 3 or 9, x = 1 or 2. D2 2ˣ = 4 (−8 rejected), x = 2.
D3 5ˣ = 2 or 3, x = 0.431 or 0.683. D4 2y² − 9y + 4 = 0, 2ˣ = ½ or 4, x = −1 or 2.
D5 3y² − 28y + 9 = 0, 3ˣ = ⅓ or 9, x = −1 or 2.

**E.** E1 2ˣ = 8 (−3 rejected), x = 3. E2 3ˣ = 5 (−2 rejected), x = 1.46.
E3 5ˣ = 1 or 4, x = 0 or 0.861. E4 4ˣ = 6 (−2 rejected), x = 1.29.
E5 7ˣ = 2 or 5, x = 0.356 or 0.827.

**F.** F1 Dividing: 2 × 9 = 2ˣ × 3ˣ, so 6ˣ = 18 and x = 1.61.
F2 3 × 6ˣ = 4ˣ ÷ 4, so (2/3)ˣ = 12 and x = lg 12 ÷ lg (2/3) = −6.13.
F3 x lg 3 = x² lg 2, so x = 0 or x = lg 3 ÷ lg 2 = 1.58. (Dividing by x loses x = 0.)

**G.** G1 5ˣ − 9 = −(5ˣ + 3) gives 5ˣ = 3, x = 0.683. The other case has no solution.
G2 3(3ˣ) − 5 = 3ˣ + 7 gives 3ˣ = 6, x = 1.63. The other case gives 3ˣ = −½, rejected.
G3 2^|x| = 4 (−1 rejected), |x| = 2, x = ±2.
G4 3^|x| = 5 (−3 rejected), |x| = 1.46, x = ±1.46.

**H.** H1 Let y = 2ˣ, which is positive. |2y − 3| < y + 3 means −(y + 3) < 2y − 3 < y + 3.
The left part gives y > 0, always true. The right part gives y < 6. So 2ˣ < 6 and
x < lg 6 ÷ lg 2.

## Notes for building

- This section is planned for `AM_5B`, with 5.7 and 5.8.
- The book teaches hidden quadratics in three steps of disguise: plain (type C), a
  shifted power (type D), a squared base (type E). Each has its own question. A levelled
  task should climb in the same order.
- "Reject the negative value" here has a different reason from 5.4: a power of a
  positive number is always positive. C7 has no solution at all, so the check is real.
- Guided questions (B1, C1, D1) come first in each group in the book. They are the
  exam's "show that … hence" framing and worth keeping as the first item of each level.
