# Add Maths 5.7 — Natural logarithms

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.7, pages 114–115. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh problem set that covers every type, with answers. None of the
problems are the book's. Every answer was checked by script.

## Part 1 — The beats of the notes

1. **A special base (p. 114).** The number e is irrational, about 2.718. It matters
   because of properties met later in the calculus chapters.
2. **Natural logarithms.** Logs to base e. ln x means logₑ x.
3. **The picture.** y = eˣ and y = ln x are reflections of each other in y = x.
4. **The link.** If y = eˣ then x = ln y. They are inverse functions.
5. **Nothing new to learn.** Every rule of logarithms so far applies to ln.

There are no worked examples in this section. The exercise carries the teaching.

## Answers

**A.** A1 20.1. A2 1.65. A3 11.0. A4 0.368. A5 0.0821.

**B.** B1 2.20. B2 1.28. B3 4.61. B4 −0.693. B5 −2.53.

**C.** C1 9. C2 7. C3 12. C4 1/5. C5 −4. C6 9. C7 3. C8 4. C9 −2. C10 ½.

**D.** D1 12. D2 0.4. D3 x² = 49, so x = 7 (x must be positive for ln x to exist).
D4 1/x = 8, so x = 1/8. D5 x³ = 64, so x = 4. D6 2x = 9, so x = 4.5.

**E.** E1 3.69. E2 0.903. E3 0.197. E4 2.40. E5 1.61. E6 −0.0247.

**F.** F1 ln 11. F2 ln 4. F3 (ln 5 − 1)/3. F4 (ln 12 − 5)/2. F5 −ln 2.

**G.** G1 7.39. G2 0.223. G3 51.6. G4 3.13. G5 2.28. G6 12.2.

**H.** H1 3 ln x = 9, x = e³ = 20.1. H2 x = ln 5 − 5 = −3.39.
H3 (x + 4)/x = e², x = 4 ÷ (e² − 1) = 0.626. H4 2x + 1 = e⁴/3, x = 8.60.

**I.** I1 e³ − 2. I2 (ln 10 − 2)/3. I3 eˣ(eˣ − 6) = 0, so x = ln 6 (eˣ is never 0).
I4 e²ˣ = 5, x = ½ ln 5. I5 eˣ = 3 or 4, x = ln 3 or ln 4. I6 Multiply by eˣ:
e²ˣ − 6eˣ + 8 = 0, eˣ = 2 or 4, x = ln 2 or ln 4. I7 eˣ = 3 (−2 rejected), x = ln 3.

**J.** J1 eˣ = 5 (−2 rejected), x = 1.61. J2 eˣ = 1 or 7, x = 0 or 1.95.
J3 e²ˣ − 30eˣ + 3 = 0, eˣ = 29.9 or 0.100, x = 3.40 or −2.30.

**K.** K1 2 ln y = 4, so y = e² and x = e⁶. K2 The equations give y = 3x − ln 2 and
y = 2x − ln 7. So x = ln 2 − ln 7 = ln (2/7) and y = ln (4/343).

**L.** L1 ln (9 − e²ˣ) = 1.5, e²ˣ = 9 − e^1.5, x = 0.754.

**M.** M1 x(e²ˣ − e³) = 0, so x = 0 or x = 3/2. M2 eˣ(x² − 4) = 0, so x = 2 or −2.

**N.** N1 x²(3 − eˣ) − 4(3 − eˣ) = 0, so (x² − 4)(3 − eˣ) = 0: x = 2, −2 or ln 3.
N2 e²ˣ(eˣ − 4) − (eˣ − 4) = 0, so (e²ˣ − 1)(eˣ − 4) = 0: x = 0 or ln 4.
