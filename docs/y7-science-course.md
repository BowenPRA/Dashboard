# Year 7 Cambridge Science — the course spine

The self-study track `Y7_SCI` (Cambridge Lower Secondary Science 7, Learner's
Book), the twin of the classroom `y7-science` course. Read
[classroom-dashboard-pairing.md](classroom-dashboard-pairing.md) first — every
unit here is a reduction of a deck taught in the room, and that doc is the
contract for how the reduction is made.

## 1. The unit = one Learner's Book section

Same rule as Maths ([y7-math-course.md](y7-math-course.md)): one Cambridge
section is one app unit, zero-padded so it sorts in book order (`U01_1` …
`U02_2`). Where the classroom taught a section as two lessons (`U02_1a` +
`U02_1b`), the Dashboard unit absorbs both and lists both in
`meta.classroom`.

**Bilingual EN + VN, always.** Same students as Maths, and the science words
("organelle", "compress", "condensation") *are* half the lesson.

## 2. The unit shape

Eight scored tasks (nine in 2.2). **145–160 XP is available and the unit caps
at 100**, so a student can drop a whole task and still finish. Two gates, both
under the 80% rule ([phase-gate-80-percent-rule]). The shape was redesigned on
2026-09-10 for engagement — read [y7-science/ENGAGEMENT-PLAN.md](y7-science/ENGAGEMENT-PLAN.md)
for why each task is there.

| Order | Phase | Gate | Task | XP | Size |
|---|---|---|---|---|---|
| 1 | `concept` | 0 | `NOTES` — the deck | 20 | 16–20 slides, **5–6 scored items: checks + interactive activities** (sort · order · estimate · hotspot · predict); the starter is an activity, never a paper task |
| 2 | `concept` | 0 | `WORD_REC` — Vocab | 15 | 8–9 key words, audio |
| 3 | `practice` | 25 | `WORKBOOK` — Practice | 20 | **10–12 mixed-type questions**: sort, order, dropdown, fill-in, typed, MCQ |
| 4 | `practice` | 25 | `LABEL_IT` — Label It | 20 | **2–3 of the unit's own diagrams**, labels stripped, pins to fill |
| 5 | `practice` | 25 | `READ_COMP` — Reading | 15 | **3 cloze passages** |
| 6 | `practice` | 25 | `SHORT_ANSWERS` — Questions | 20 | **4 reasoning Qs**, AI-marked |
| 7 | `practice` | 25 | `DIAGRAMS` — label and explain | 15 | **3 items**, AI-marked |
| 8 | `practice` | 25 | `LAB_BENCH` — Lab Bench (2.2) | 15 | **8 generated rounds**: read a cylinder, a thermometer, a heating curve |
| 9 | `mastery` | 80 | `ASSESSMENT` — Quiz | 20 | **6 MCQ**, 8 minutes |
| — | `mastery` | 80 | `GAMES` — arcade | 0 | level from `unitDifficulty.js` |

Why this differs from the Maths shape: the Workbook here is not an exercise of
answers to reveal but a **mixed-interaction** set; Label It is what the exam
asks ("label the diagram") and what a deck could only show; Lab Bench is the
one task that is never the same twice. SPELLING was dropped (a third pass over
the same words). Everything in **practice** sits before one quiz gate at 80 of
≥125 XP (≤64%).

## 3. The per-file recipe

```
src/data/Y7_SCI/<UNIT>/
  data.js        meta (id, title, desc, track, icon, classroom), phases,
                 realWords, passages, shortQA, diagrams, labelIt,
                 workbook (imported), labBench (2.2 only), + the imports below
  notes.js       the deck — layout slides, 5–6 scored items: `check:` MCQs and
                 `activity:` blocks (sort · order · estimate · hotspot ·
                 predict). Either key is the LAST key on its slide; never both.
  workbook.js    10–12 mixed-type questions (mcq, inline, fill_blank, dnd,
                 order, text) — see ENGAGEMENT-PLAN §2.4 and the maths
                 docs/y7-math/WORKBOOK-AUTHORING.md for each type's shape
  diagrams.js    copied verbatim from the classroom lesson (diagramsB.js for a
                 second absorbed lesson)
  widgets.jsx    copied from the classroom lesson, photo imports rewritten to
                 assetUrl(...)
  assessment.js  { timeLimit: 480, passages: [], questions: [6 × mcq] }
  games.js       arcadeConfig('Y7_SCI', '<UNIT>')
public/images/Y7_SCI/<UNIT>/   the licensed photographs (never lb-* scans)
public/audio/Y7_SCI/<UNIT>/    generated by `npm run sync-audio`
```

### Interactive activities (`activity:` on a slide)

The starter of every deck is an activity, and one or two more sit mid-deck.
Shapes are in [y7-science/ENGAGEMENT-PLAN.md](y7-science/ENGAGEMENT-PLAN.md)
§2.1; `src/utils/activity.js` validates them. Two traps: a `hotspot` needs the
diagram's coordinates (`node scripts/svg-coords.mjs Y7_SCI/<UNIT> <KEY>` prints
every text/circle position) and the renderer strips the printed labels so the
answer does not leak; activity items use `name`/`explain` rather than `text`
so the narration generator does not read the answers aloud.

### Label It (`labelIt`)

Two or three items, each one of the unit's own diagrams:
`{ id, title, titleVn, inlineSvg: DIAGRAMS.X, viewBox, pins: [{ id, x, y, answer }], bank: [{ val, text, textVn }] }`.
Pins sit where the printed label was (`svg-coords.mjs` again); the bank needs
at least one distractor. `src/utils/labelIt.js` grades it; the student checks
pin by pin and the wrong ones show the right label.

### Lab Bench (`labBench`, 2.2 only)

`{ modes: ['cylinder', 'thermometer', 'curve'], rounds: 8, title, titleVn }`.
Rounds are generated from a seed (`src/utils/labBench.js`), so every attempt
reads different instruments; "New readings" reseeds.

### Vocabulary (`realWords`)
8–9 words. Take the copy-down definitions from the deck's `write` notes, then
add the one or two words the *questions* lean on that the book never defines
("similar", "specimen", "trillion"). `def` is one plain sentence; `sent` uses
the word in the unit's own context. No `fakeWords` needed.

### Reading (`passages`)
Three passages of 80–110 words each, in the register of the Learner's Book,
covering the deck in order. Blanks are `{word}` and must be words from
`realWords` (the task shows the first letters as a hint, so a blank that is
not a taught word is a guess). Two or three blanks per passage.

### Questions (`shortQA`)
Four, two marks each, one mark per `markScheme` line. They are the deck's
ask-first questions and the book's page questions, rewritten so a student
can answer from the deck: "explain why", "compare", "what is the clue". The
`vnTranslation` is the whole question in Vietnamese. See
[question-quality.md](question-quality.md) for suggested words and the
grading model.

### Diagrams (`diagrams`)
Three items, each on one of the unit's own SVGs (`DIAGRAMS.X`), 2–3 marks:
name the parts, state the function, explain the mechanism. Pick the diagrams
that carry the *idea* (the three-arrangements picture, the heating curve, the
five-levels ladder), not the decorative ones.

### Quiz (`assessment`)
Six MCQ, four options, correct letters spread so no letter is never right
(the validator warns). 1–2 key words in context, 3–5 the core idea, 6 a
transfer question the deck did not answer directly (the jellyfish, the sperm
cell). Every explanation says why each distractor is wrong.

## 5. Verify

`preview-y7sci.html?unit=<UNIT>` mounts every task without login (`&slide=N`
resumes the deck at slide N to test the checkpoint)
(`http://localhost:5173/Dashboard/preview-y7sci.html?unit=U02_1`). Then
`npm run validate`, `npm run audit:svg Y7_SCI`, `npm run lint`. The arcade
level for each unit is in `src/components/towerdefense/unitDifficulty.js`
(`TRACK_LEVELS.Y7_SCI`) — add a row when a unit is added, or it plays flat.
