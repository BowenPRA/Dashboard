# U01_1 · 1.1 Adding & Subtracting Integers

**Objective:** I can add and subtract positive and negative integers using a number line.
**Key words:** integer, inverse, number line, positive, negative
**Materials:** projector, mini-whiteboards · **Time:** ~45 min

## Warm-up (5 min) — answers
1. 7 + 3 = 10 · 7 − 3 = 4
2. Inverse of 5 is −5 · inverse of −2 is 2
3. Move **left** to make a number smaller

## Sequence
| Min | Slide / activity | Teacher does |
|-----|------------------|--------------|
| 0–5 | Title + Do Now | Settle class; take Do Now answers on whiteboards |
| 5–12| The Number Line | Draw the line; establish right = larger, left = smaller |
| 12–22| Adding Integers | Model $-3+-4$ on the line, then $8+-12$ (past zero) |
| 22–28| Subtracting a Positive | Quick: $4-6$, $-6-3$ — same "move left" |
| 28–36| Subtracting a Negative | **The big idea:** $2--5=2+5=7$; $-6--9=3$. Turn $--$ into $+$ |
| 36–40| **Discussion:** why does subtracting a negative make it bigger? | Cold-call; use the temperature idea |
| 40–44| **Your Turn** (whiteboards) | $20+-5$, $-10--15$, $-2+-13$; partners check |
| 44–45| Summary + exit ticket | Exit below |

## Discussion questions
- Why is subtracting a negative the same as adding? (you undo a downward step → you go up / add the inverse)
- Where do we meet negative numbers in real life? (temperature, money owed, floors below ground)

## Exit ticket
Work out **−6 − −9**. (Expect **3**: rewrite as −6 + 9.)
This is exactly End-of-Unit-1 Test Q1b — plus Q1a is **8 + −12 = −4**.
Anyone who misses it → Workbook Focus f6–f9 next lesson.

## Test coverage (1.1 → End-of-Unit 1 Test)
- **Q1a** 8 + −12 → adding a negative (Adding Integers slide; Workbook f2/f8).
- **Q1b** −6 − −9 → subtracting a negative (Subtracting a Negative slide; Workbook f6/f7/f9).
