# U05_1 · 5.1 A sum of 360° (self-study)

The self-study twin of the classroom deck `y7-math/U05_1` (26 slides, one period).
**English and French only** (`meta.vietnamese: false`). One idea runs through it: **find a
missing angle and say why** — which fact (on a straight line 180°, round a point 360°, in a
quadrilateral 360°), add what you know, take it away from the total, then give the fact as
the reason. The deck meets each fact and predicts before it is told; one engine does the
section's work. Approved 2026-10-29 with one change: **fade the scaffold** (below).

**Objective:** I can read an angle diagram (a number is known, a letter is missing, a small
square is 90°); find a missing angle on a straight line, round a point and in a
quadrilateral in two steps; share what is left between equal angles; use the opposite
angles of a parallelogram; and give the fact as my reason.
**Classroom twin:** `meta.classroom` → `y7-math/U05_1`. Back-link: integrator.

## Find It, Say Why — `ANGLE_SUM` (p81), unit key `angleSum`
`utils/angleSum.js` (model, stages, slips, messages) · `utils/angleSumGeometry.js` (the
figure, to scale) · `utils/angleSumCheck.js` (the proof) · `components/math/useAngleSteps.js`
(the step runner, shared) · `AngleSumStage.jsx` + `angleSumText.js` (the stage panel) ·
`AngleSumFigure.jsx` · `tasks/AngleSum.jsx` · deck activity `anglesum`
(`components/notes/AngleSumActivity.jsx`, in Notes' `SIDE_ACTIVITIES`).

```js
angleSum: {
  title, titleFr, intro?, introFr?, levels: { 1: { en, fr }, … },
  items: [
    { id: 'l2', level: 1, kind: 'line',  angles: [44, 'b', 57] },       // in order along the line
    { id: 'p2', level: 2, kind: 'point', angles: ['R', 115, 'd', 80] }, // 'R' = a small square, 90°
    { id: 'q3', level: 3, kind: 'quad',  angles: ['R', 104, 'h', 118], context, contextFr },
    { id: 's1', level: 4, kind: 'quad',  angles: [126, 'k', 'k', 'k'] }, // the same letter = the same size
    { id: 't1', level: 5, kind: 'straight', angles: [67, 111] },         // is XY a straight line?
    { id: 'c1', level: 6, kind: 'quad',  angles: [95, 110, 'x', 82], ext: { at: 2, angle: 'y' } },
    { id: 'c3', level: 6, kind: 'para',  angles: [58, 'p', 'q', 'r'] },
  ],                                                                    // + walk: true | false
}
```
Whole degrees. `ext` draws the side arriving at corner `at` on past it: a straight line
with that corner (its angle a number or a letter). A `para` gives one corner. A context
must give each of its numbers, and say "right angle" for a small square.

**Stages, per letter (walked):** *First* (two letters left: tap the one that is the only
unknown in its fact) → *180 or 360* → *Add* (task: tap the known angles on the figure,
small squares and found letters included, decoys refused; deck: the same angles as
buttons; then type the total — skipped with one known) → *Subtract* → *Share* (equal
letters) → *Say why* (three sentences). A parallelogram's opposite angle: *Opposite*
(typed) → *Say why*. `straight`: *Add* → *Say why* (verdict and reason together).

**The fading rule.** Levels 1–2 walk every stage. From level 3 (`WALK_UP_TO = 2`; an item's
`walk` overrides; a deck activity walks unless `walk: false`) a letter opens **quick**:
*First* if two letters are left, then the angle typed and the reason picked together.
- Both right → the letter is done, clean.
- A wrong angle → its slip is named and the stages open **at the stage the slip belongs
  to** (`slips[].stage`, via `openAt`: `point180`/`line360`/`quad180` → 180 or 360;
  `forgot`/`forgotRight`/`decoy` → Add; `noSub` → Subtract; `noShare`/`shareAll`/`allEqual`
  → Share; `notOpp` → Opposite; a value no slip explains → the first working stage). The
  stages before it are marked as given; the quick wrong answer counts as that stage's first.
- A right angle with a wrong reason → only *Say why* opens, the wrong sentence struck.
- *Say why* is never skipped. Show me in quick opens the stages with the first one filled.

**Named slips:** `twoUnknown`; `point180`, `line360`, `quad180`; `forgotRight` (the small
square), `forgot`, `decoy` (the angle outside the shape), `letter` (deck: the letter
tapped as known), `addArith`; `noSub`, `subArith`; `noShare`, `shareAll` (÷ 4 not ÷ 3),
`allEqual` (360 ÷ 4), `shareArith`; `notOpp`, `oppArith`; `wrongFact` (a true fact about
another diagram), `wrongNumber`, `nextDoor`, `looks` ("it looks like 52°" / "it looks
straight"); `close`, `twoOnly`, `rounded`, `totalArith` (straight). Each answer is named
and tried again; a second wrong, a two-way choice got wrong, or Show me fills the stage in
and the item pays ½. Blob `{ id: 1 | 0.5 }`, out of 10.

**Figure:** to scale (unlike the book): 178° looks straight on purpose. Lines tilted and
points turned by a hash of the id; quadrilaterals built from their angles (edge directions
turn by 180° − each angle; two sides chosen, two solved so it closes). Known teal, the
letter being found orange, found letters green with their value; labels laid out for the
value they will show.

**Proof** (`checkAngleSumItems`, the `@@U05_1_CHECK@@` marker; `checkAngleSumActivity` for
the deck): every stage accepts its own answer; every slip's canonical value is named by its
own code and opens its stage; refused: a slip equal to the answer, two slips sharing a value
but opening different stages, a find-first with more than one right letter, labels that
overlap or leave the picture, a corner outside 35°–150°, a thin quadrilateral, two small
squares in a quadrilateral, a "straight" sum more than 15° from 180°. 173 cases over the 15
items and 4 deck activities; a Node fuzz of 4000 random items proved 3436 and refused the
rest by name (overlapping labels, thin shapes, collisions).

**Levels (15 items, fresh numbers):** 1 on a line (a = 52, b = 79) · 2 round a point (c =
115, d = 75 with a small square, e = 214 reflex) · 3 in a quadrilateral (f = 68, g = 83 with
a small square, h = 48 the garden) · 4 the same size (k = 78, n = 70) · 5 is it straight?
(178°: no; 180° in three angles: yes) · 6 two steps (x = 73 → y = 107; v = 116 → u = 60 with
64° outside; parallelogram q = 58 → p = r = 122).
