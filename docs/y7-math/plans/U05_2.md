# U05_2 · 5.2 Intersecting lines (self-study)

The self-study twin of the classroom deck `y7-math/U05_2` (26 slides, one period,
EN/FR; `plan.js` holds the Workbook 5.2 answer key). **English and French only**
(`meta.vietnamese: false`). Conventions settled for this deck and kept everywhere here:
the **F stands upright** (line across leaning back, angles under each arm), the **Z is
never mirrored** (top arm left, bottom arm right, angles inside the corners), no diagram
prints the answer to the question beside it, no slide shows two figures of the same
thing, and no "transversal" or "co-interior" on any learner-facing screen (the
same-side pair is "between the lines, on the same side: 180°").

**Objective:** find vertically opposite angles; say what parallel and perpendicular lines
are and read their marks; use corresponding (F) and alternate (Z) angles, and know they
only work when the lines are parallel (arrows); give every answer with its reason —
"x = 53° because they are alternate angles."
**Key words (WORD_REC, 7):** intersecting · vertically opposite · perpendicular ·
parallel · corresponding · alternate · give a reason.
**Classroom twin:** `meta.classroom` → `y7-math/U05_2`; back-link at integration.

## X, F or Z? — `anglePairs` (`ANGLE_PAIR`, p82)
**Why a new engine.** Nothing in the registry draws two lines and a line across, and the
section's real work is *seeing which pair you are looking at* (X, F, Z, a straight line,
or none because there are no arrows), then the size, then the reason. Files:
`src/utils/anglePairGeom.js` (the deck's `lines.js`/`tracks.jsx` geometry: sectors,
relations, letter shapes, label places) · `src/utils/anglePairs.js` (stages, slips,
sentences, checks) · `src/components/math/AnglePairFigure.jsx` (tappable sectors) ·
`src/tasks/AnglePairs.jsx` · `src/components/notes/AnglePairActivity.jsx` (deck type
`anglepair`, kinds `spot` and `find`).

```js
anglePairs: { title: 'X, F or Z?', titleFr: 'X, F ou Z ?', intro, introFr, levels: { 1: { en, fr }, … },
  items: [
    { id: 'p1', level: 1, kind: 'spot', fig: { type: 'x', a: 18, th: 47 }, given: [0, 1], ask: 'opp' },
    { id: 'p4', level: 2, kind: 'find', fig: { type: 'pair', a: 0, th: 138 }, given: [0, 3], find: [{ at: [1, 3], letter: 'x' }] },
    { id: 'p9', level: 4, kind: 'find', fig: { type: 'pair', a: 12, th: 122, arrows: false }, given: [0, 3],
      find: [{ at: [1, 3], letter: 'x' }, { at: [0, 1], letter: 'y' }] },             // x: can't tell · y: an X
    { id: 'p11', level: 5, kind: 'steps', fig: { type: 'pair', a: 0, th: 126 }, given: [0, 3], find: [{ at: [1, 0], letter: 'z' }] },
    { id: 'p13', level: 6, kind: 'which', fig: { type: 'three', a: 0, th: 74, bends: [0, 0, 4] },
      given: [[0, 3], [1, 0], [2, 1]], context, contextFr },                            // which rail is not parallel?
  ] }
```
An item states only the picture (line directions; `[crossing, sector]`, sectors 0–3
anticlockwise from the line's own direction) and what is asked. The engine derives every
angle, the relation, the answer, the reason sentence, the slips and the letter to draw.

**Stages** (derived):
- *Tap* (`spot`, levels 1–2 only) — "Tap the angle vertically opposite the 133°."
- *Pair* — X · vertically opposite / F · corresponding / Z · alternate / a straight line,
  180° / no arrows: you can't tell (an X figure offers the first and fourth).
- *Size* — the final answer, typed; none when it is "You need more information".
  Then the full sentence, in English in both languages (French gloss in brackets, as the
  deck does): "x = 104° because angles on a straight line add up to 180°."
- *Stone* (`steps`) — "You can't reach z in one step. Tap an angle you can find first."
- *Line* (`which`) — tap the line that is not parallel; the angles are printed in
  different places. Then *Pair* in its reason form: "its angle in the same place is
  different" / "it does not meet the side at 90°" / "it looks tilted".

**Two or three actions, and Pair always stays.** Levels 1–2 teach (Tap; or Pair + Size).
From level 3 on, every item is two or three actions:
`find` = Pair + Size · the two-letter no-arrows item = Pair, Pair, Size · `steps` =
Stone + Pair + Size · `which` = Line + reason. Tap appears only when the question does
not already mark the angle. Size is typed only for the final answer: a step on the way
whose size the pair makes obvious is never typed. **Extra stages open only after a wrong
answer, where the slip happened:** a wrong final size in `steps` opens "What is this
angle first?" on the stepping stone; a wrong line in `which` opens "Move this line's
angle to the same place" for the line tapped; then the stage that went wrong is retried.

**Named slips:** pair/tap — `opp`, `corr`, `alt`, `adj` ("next to it on a straight
line: together 180°"), `side` ("between the lines on the same side: 180°, not equal"),
`twostep` (equal or 180°, but not by one X, F or Z), `noarrows` (F or Z chosen with no
arrows), `needless` ("can't tell" for an X, which needs no parallel lines), `self`;
size — `supp` (180 − g for an equal pair), `same` (g for a 180° pair), `full` (360 − g),
`comp` (90 − g), `arith`; stone — `given`, `target`, `deadend`, `far`; line — `printed`
(compared the printed numbers, not the same place); reason — `perp`, `eye`. A wrong
answer is named and tried again; a second wrong or "Show me" fills the stage and the
item pays ½. Blob `{ id: 1 | 0.5 }`, score out of 10.

**Levels (14 items, fresh numbers):** 1 two lines cross (spot an X; find a straight
line) · 2 F (spot; find) · 3 Z (find, given at the top; find, given at the bottom) ·
4 X, F, Z or none? (tilted pictures: a straight line, a Z, an F; one no-arrows picture
with x = "can't tell" and y an X) · 5 two steps (the same-side pair; an equal pair two
steps away) · 6 are they parallel? (three rails, angles in different places, the odd one
4° off so the eye cannot decide). Level 6 is the first thing to cut if time runs short.

**Shapes, strictly.** Every F the engine draws is the upright F (line across leaning
back, angles under the right-hand arms: sector 3 at both crossings); every Z is the true
Z (line across leaning forward, sectors 2 and 0: top arm left, bottom arm right). Variety
comes only from tilting the whole picture (≤ 40°) and from the X / F / Z / straight line
/ can't-tell mix. The validator refuses any item whose asked or stepping-stone pair
would draw another F or Z. A student's valid answer through another pair (a stepping
stone reached by a back-to-front F, say) is still marked right; it lights the two
angles and draws no letter.

**Proof (`checkAnglePairItems` at the validator marker; `checkAnglePairActivity` at the
activity marker):** every figure fits its frame and every label sits inside its sector,
clear of the lines and the other labels; `th` is 20–160 and never 85–95 (equal and 180°
would coincide); the asked relation is one step for `spot`/`find` and two for `steps`,
with at least one stepping stone whose two links draw allowed letters; `which` has
exactly one odd line, 3–8° off; each stage accepts its own answer and every slip's
canonical wrong answer is named by its own code, no two sharing a value; bilingual level
names and contexts are present. A Node fuzz runs the same proof over random figures.

## Short Answers (3 × 3 marks, `frTranslation`, mark-scheme only)
sq1 Lan's mistake: the angle opposite 64° is not 116° "because of a straight line": name
the X, give 64°, write the sentence. · sq2 Explain in two steps why the alternate angle to
a 70° is 70° (corresponding, then vertically opposite: the Z_PROOF argument in their own
words). · sq3 Mr Bowen's fence: rails at 78°, 78° and 74° to one post, in the same place:
which rail is not parallel, and why (corresponding angles are equal only when the lines
are parallel).

## Quiz (8 MCQ, `$$…$$` only, static diagrams in `diagrams.js`)
1 which lines are perpendicular / parallel (labelled lines) · 2 X: "p = … because …", the
answer and the reason in one option · 3 F, the same format · 4 which lettered angle is
alternate to 47°? · 5 no arrows: which statement · 6 two steps (same side) · 7 which line
is parallel (angles in different places) · 8 a road across two railway lines, in words.
Distractors: the wrong pair, 180 − g for an equal pair, g for a 180° pair, "it looks
equal", "the lines look parallel".
