# Lesson Plans — the One-Page Teacher Plan

A short plan the teacher glances at while running the projected lesson. **One page,
skimmable, no fluff.** It is for you, not the students — so it holds the things the
slides don't: warm-up answers, timings, the questions to ask, and the exit check.

- **Lives at:** `docs/y7-math/plans/<unitId>.md` (e.g. `docs/y7-math/plans/U01_1.md`).
  Plans are teacher docs, so they sit in `docs/`, not in `src/data/`.
- **One per section**, alongside that section's `notes.js` + `workbook.js`.
- Keep it **English-only** — it's your reference, not learner-facing.

---

## Template

```markdown
# U01_1 · 1.1 Adding & Subtracting Integers

**Objective:** I can add and subtract positive and negative integers using a number line.
**Key words:** integer, inverse, number line, positive, negative
**Materials:** projector, mini-whiteboards · **Time:** ~45 min

## Warm-up (5 min) — answers
1. 7 + 3 = 10   2. 7 − 3 = 4   3. Left (to subtract, move left)

## Sequence
| Min | Slide / activity | Teacher does |
|-----|------------------|--------------|
| 0–5 | Title + Do Now | Settle, take answers on whiteboards |
| 5–20| Concepts 1–3 (number line, adding negatives) | Model on the number-line widget; class predicts |
| 20–25| **Discussion:** why does subtracting a negative move right? | Cold-call, build the rule together |
| 25–35| **Activity:** partners place 4 numbers on the class number line | Circulate, check signs |
| 35–43| Workbook task (Focus + Practice) | Students self-check with reveals |
| 43–45| Summary + exit question | Exit: work out −5 + −6 on a whiteboard |

## Discussion questions
- Why is subtracting a negative the same as adding? (adding the inverse)
- Where do we use negative numbers in real life? (temperature, money owed)

## Exit ticket
−5 + −6 = ?  (Expect −11.) Anyone who misses it → Focus Q1–2 tomorrow.

## Resources (optional)
- [Number line intro — video](https://…)  ← link only, not embedded in slides
```

---

## Rules

- **Fits on one screen.** If it spills, cut — the slides carry the content; the plan
  carries the *running of it*.
- **Timings are a guide**, but include them — they keep the projected lesson to the
  period.
- Always include: **objective**, **warm-up answers**, a **sequence table**, the
  **discussion question(s)**, and an **exit ticket** that tests the objective.
- Put **video/website links here**, not in the slide deck (keeps the deck offline-safe
  — see [math-lessons.md](math-lessons.md) §7).
- Mirror the lesson's language and Key words so plan, slides, and workbook agree.
