# 6.3 Oxides — unit plan (IGCSE_CHEM / M06_3)

Wolsey Hall Module 6, Topic Three (6.3). Built from book spread **11.5 "Oxides"**
(pages 136–137), with the Chapter 11 Checkup (page 144) as the guide to what the exam
asks. An **equations** unit in the shape of `M06_2`, with one production engine.
English-only (`bilingual: false`), so no `vn*` twins.

Recaps 6.2 in one slide. Stops before 6.4 (the methods for making salts, 11.6).

## Objective

The student can define an **oxide**; describe calcium, iron and copper reacting with
oxygen and write the balanced equations; state that the more reactive the metal, the
more vigorous the reaction; show with litmus that copper(II) oxide, though insoluble in
water, dissolves in acid and **neutralises** it, so it is a **basic oxide**; state that
metals form basic oxides and that basic oxides are bases; describe carbon, sulfur and
phosphorus burning and write the equations (P₄ + 5O₂ → P₄O₁₀); state that non-metal
oxides dissolve in water to give acids (CO₂ + H₂O → H₂CO₃), so they are **acidic
oxides**; explain **acid rain**; know the **neutral** oxides CO and N₂O. **Extended:**
define an **amphoteric oxide** and give Al₂O₃ and ZnO, with the book's two aluminium
oxide equations; the basic → amphoteric → acidic pattern across period 3.

## The mistakes the unit is built around

| Mistake | Where it is caught |
|---|---|
| Counting a hydroxide or carbonate as an oxide ("it has oxygen in it") | deck c2, workbook f1, quiz 1 |
| Reading "basic" as "simple" | deck English slide c4 |
| Thinking an insoluble oxide cannot be a base / must turn litmus blue | deck a3, c5, c6, workbook p1, quiz 4, Source Analysis 1, Questions sq1 |
| All metals burn alike (vigour not linked to reactivity) | deck a1, a2, c3, quiz 3, Questions sq2 |
| Metal ↔ non-metal oxide kinds swapped | deck a4, a5, c8, c14, workbook f2, f3, p3, quiz 5, Source Analysis 2 |
| Acid rain blamed on the wrong oxides, or its effect treated as its cause | deck c9, workbook f4, quiz 7, Questions sq4, Source Analysis 3 |
| "A metal oxide must be basic" (aluminium oxide) | deck a6, c10, workbook c1, c2, quiz 10, Questions sq5 |
| Amphoteric and neutral confused; CO confused with CO₂ | deck c11, a7, workbook p5, quiz 8, 9 |
| Oxide formulae that ignore the charges (MgO₂, NaO, AlO), O for O₂, -ous/-ic acids swapped | Equations banks |

## Equations (`SYMBOL_EQ`, 8 items, all fresh)

2Mg + O₂ → 2MgO · 4Na + O₂ → 2Na₂O · 4Al + 3O₂ → 2Al₂O₃ · N₂ + 2O₂ → 2NO₂ ·
Fe₂O₃ + 6HCl → 2FeCl₃ + 3H₂O · ZnO + H₂SO₄ → ZnSO₄ + H₂O · SO₂ + H₂O → H₂SO₃ ·
CO₂ + 2NaOH → Na₂CO₃ + H₂O. Every item passes `checkItem`. None is a book example (the
book's C, S, P, Ca, Fe, Cu, CuO + HCl, CO₂ + H₂O and the two Al₂O₃ equations are taught
in the deck). `SymbolEquation.jsx` shows each `note` as a hint **before** the answer, so
the notes name the method (ion charges, which atom to balance first) and never state a
formula or coefficient.
