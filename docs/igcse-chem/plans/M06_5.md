# 6.5 The Periodic Table — unit plan (IGCSE_CHEM / M06_5)

Wolsey Hall Module 6, Topic Five (6.5). Built from book spreads **12.1 "The Periodic
Table: an overview"** (pages 146–147), **12.4 "More about the trends"** (152–153) and
the history pages **"How the Periodic Table developed"** (156–157), with the Chapter 12
Checkup (158–159) as the guide to what the exam asks. English-only
(`bilingual: false`), so no `vn*` twins.

Group I (12.2), Group VII (12.3) and the transition elements (12.5) are the next three
units (6.6, 6.7, 6.8). This unit names them as "coming next" and places them on the
table; it teaches none of their reactions.

## Objective

The student can say that the table is in order of **proton number** and read a box
(proton number, symbol, name, relative atomic mass); explain **periodicity**; find
**groups** (I–VIII) and **periods** (1–7); use the **zig-zag line** (metals left, over
80% of elements; hydrogen alone; the transition block in the middle); state **group
number = outer-shell electrons** (I–VII) and **period number = shells**; explain why the
**noble gases** are unreactive and monatomic; predict properties from position; give the
**charge on the ion** from the group (I 1+, II 2+, III 3+, VI 2−, VII 1−).
**Extended:** why reactivity rises down Group I and falls down Group VII (shells, the
pull of the nucleus); fewer electrons to lose or gain = more reactive; density down a
group; trends across Period 3 (metal → metalloid → non-metal, basic → amphoteric →
acidic oxides); silicon as a metalloid. **History:** Newlands's octaves and why they
failed; Mendeleev's gaps and predictions; atomic weight vs proton number
(potassium/argon).

The Checkup lists "group number and the charge on ions" under **Core**, so the deck
teaches it without an Extended eyebrow; the shells / reactivity / Period 3 slides carry
`eyebrow: 'Extended'`.

## The mistakes the unit is built around

| Mistake | Where it is caught |
|---|---|
| Ordering by relative atomic mass | deck c1, quiz 1, workbook c3 (tellurium/iodine), deck a9 |
| Swapping the period and group rules (2,8,5 → Period 5) | deck c5, workbook f2 and p2, quiz 2, Questions sq1 |
| Reading the bottom number of a box as protons or neutrons | deck c2, workbook f1 |
| Group = row / period = column | deck a1, Element Hunt `place` |
| Taking the group number as the charge (Group VI → 6+) | deck a6, workbook p1, quiz 4, sq4 |
| Counting helium in Group II (two electrons) | deck a4 explain, workbook f4 |
| "Down the group = more reactive" for non-metals too | deck c7, sq3 |
| More outer electrons = more reactive (calcium > potassium) | deck c8, workbook c2, quiz 7 |
| Newlands left gaps / Mendeleev had none | deck c10, c11, predict a8, sq5 |

## Element Hunt (`elementHunt.js`)

The Year 7 engine, unchanged. A unit chooses only modes and rounds; the engine writes the
questions, marks them and explains them, drawing every round fresh on the first-20 table.
It runs English-only here (the registry passes `bilingual` from the track, and
`checkHuntConfig` needs no `titleVn`).

`modes: ['place', 'metal', 'place', 'mass', 'place', 'metal']`, `rounds: 12` → 6 place
(one element by period + group, a whole period or group, "the others in the same group /
period as …"), 4 metal (every metal or non-metal in a period, or one element), 2 mass
(heavier atoms; argon/potassium never asked). `find`, `symbol` and `name` are Year 7
symbol recall and are left out. The engine has **no** query for outer electrons, shells
or ion charges — the deck's `periodic` activities and the Practice set carry those. Its
metal rounds count silicon as a non-metal (right of the line, as in 12.1); slide 16 says
so where it teaches the metalloid.
