# Add Maths 5.9 — The graphs of simple logarithmic and exponential functions

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.9, page 118. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh set of investigations and questions in the same style, with answers.
None of them are the book's.

## Part 1 — The beats of the notes

1. **The two curves together (p. 118).** y = eˣ and y = ln x drawn on one diagram with
   the line y = x.
2. **The graph of y = eˣ.**
   - crosses the y-axis at (0, 1)
   - is positive for every x
   - gets closer and closer to 0 as x becomes large and negative, written "as x → −∞,
     y → 0"
   - the negative x-axis is an asymptote
   - grows without limit as x → +∞
3. **The graph of y = ln x.**
   - crosses the x-axis at (1, 0)
   - exists only for positive x
   - goes down without limit as x → 0
   - the negative y-axis is an asymptote
   - grows without limit as x → +∞
4. **Why they match.** They are inverse functions, so each is the mirror image of the
   other in y = x.

There are no worked examples.

## Part 2 — What the exercise asks

Exercise 5.9 is on page 118: two investigations with graphing software.

| Type | Book question | What it asks |
|---|---|---|
| A. Families of exponential curves | 1 (three parts) | Plot a family for several positive and negative values of a constant k, where k is in the power, multiplies the function, or is added to it. Describe the properties of each family. |
| B. Families of logarithmic curves | 2 (three parts) | The same for ln: k inside the log multiplying x, k multiplying the log, k added inside the log. Describe the properties of each family. |

## Part 3 — Fresh investigations and questions

### A. Families of exponential curves

Use graphing software. For each family, plot the curve for k = 4, 2, 1, −1, −2 and −4.
Then answer the questions.

- A1. y = e^(kx)
  1. Which point do all six curves pass through?
  2. What is the asymptote of every curve?
  3. What is the effect of making k negative?
  4. What is the effect of making k larger?
- A2. y = keˣ
  1. Where does each curve cross the y-axis?
  2. What is the asymptote of every curve?
  3. What is the effect of making k negative?
- A3. y = eˣ + k
  1. Where does each curve cross the y-axis?
  2. What is the asymptote of each curve?
  3. For which values of k does the curve cross the x-axis?

### B. Families of logarithmic curves

Plot the curve for k = 4, 2, 1, −1, −2 and −4. Then answer the questions.

- B1. y = ln kx
  1. For which values of x does the curve exist when k is positive? When k is negative?
  2. Where does each curve cross the x-axis?
  3. Use a law of logarithms to explain why, for positive k, each curve is y = ln x
     moved up or down.
- B2. y = k ln x
  1. Which point do all six curves pass through?
  2. What is the asymptote of every curve?
  3. What is the effect of making k negative?
- B3. y = ln (x + k)
  1. What is the asymptote of each curve?
  2. Where does each curve cross the x-axis?
  3. Which of the curves cross the y-axis, and where?

### C. Quick questions without software

For each curve, write down the coordinates of the point where it crosses an axis and the
equation of its asymptote.

- C1. y = eˣ + 3
- C2. y = −eˣ
- C3. y = e⁻ˣ
- C4. y = 5eˣ
- C5. y = ln (x − 2)
- C6. y = ln (−x)
- C7. y = 3 ln x
- C8. y = ln x + 1

### D. Stretch

- D1. True or false? Give a reason.
  1. eˣ can equal 0.
  2. ln x can be negative.
  3. The curve y = ln x crosses the y-axis.
  4. The curves y = eˣ and y = ln x never meet.
- D2. Find the exact coordinates of the point where y = eˣ − 2 crosses the x-axis.
- D3. Explain why y = ln 3x and y = ln x + ln 3 are the same curve, and describe it as a
  transformation of y = ln x.

## Answers

**A.** A1 (0, 1); y = 0; the curve is reflected in the y-axis, so it falls instead of
rises; the curve is steeper. A2 (0, k); y = 0; the curve is reflected in the x-axis and
lies entirely below it. A3 (0, 1 + k); y = k; only when k is negative.

**B.** B1 x > 0 when k is positive, x < 0 when k is negative; at (1/k, 0);
ln kx = ln k + ln x, so the curve is y = ln x moved up by ln k (down if k is less
than 1). B2 (1, 0); x = 0; the curve is reflected in the x-axis, so it falls instead of
rises. B3 x = −k; at (1 − k, 0); only those with positive k, at (0, ln k).

**C.** C1 (0, 4); y = 3. C2 (0, −1); y = 0. C3 (0, 1); y = 0. C4 (0, 5); y = 0.
C5 (3, 0); x = 2. C6 (−1, 0); x = 0. C7 (1, 0); x = 0. C8 (1/e, 0); x = 0.

**D.** D1 False: eˣ is positive for every x. True: ln x is negative for 0 < x < 1.
False: ln x does not exist at x = 0. True: eˣ is always above the line y = x and ln x
is always below it. D2 eˣ = 2, so (ln 2, 0). D3 By the multiplication law
ln 3x = ln 3 + ln x. It is y = ln x translated up by ln 3.
