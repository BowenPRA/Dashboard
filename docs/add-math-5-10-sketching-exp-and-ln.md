# Add Maths 5.10 — The graphs of y = ke^(nx) + a and y = k ln (ax + b)

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.10, pages 119–120. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh problem set that covers every type, with answers. None of the
problems are the book's. Every answer was checked by script.

## Part 1 — The beats of the notes

1. **Class discussion (p. 119).** One transformed exponential. With a partner, fill in
   six facts: the value of y when x = 0, the y-intercept, the value of x when y = 0,
   what y does as x → +∞, what y does as x → −∞, and the equation of the asymptote.
   Then sketch it, showing axis crossings and the asymptote.
2. **Worked example 15.** Sketch an exponential of the form ke^(nx) + a with a negative
   power and a negative constant. Steps: put x = 0 for the y-intercept; put y = 0 and
   use ln for the x-intercept; look at both ends to find the asymptote; draw.
3. **Worked example 16.** Sketch a curve of the form k ln (ax + b). Steps: put x = 0 for
   the y-intercept (left exact); put y = 0 for the x-intercept; find where the bracket
   is positive to get the domain; the edge of the domain is the vertical asymptote;
   draw.

## Part 2 — What the exercise asks

Exercise 5.10 follows the worked examples: two questions.

| Type | Book question | What it asks | How it climbs |
|---|---|---|---|
| A. The six facts | Class discussion | Fill in the features of one exponential, then sketch | One guided example |
| B. Sketch an exponential | 1 (nine parts) | Show axis crossings and the asymptote | eˣ with a constant added or taken, then e⁻ˣ, then a negative multiplier, then a multiple of x in the power |
| C. Sketch a logarithmic curve | 2 (six parts) | Show axis crossings and the asymptote | A plain bracket, a bracket that is only positive to the left, then a multiplier, then a negative multiplier |

## Part 3 — Fresh problems in the same style

### A. The six facts

- A1. Consider the function y = 3e²ˣ − 6.
  1. When x = 0, y = …
  2. The y-intercept is (…, …).
  3. When y = 0, x = …
  4. As x → +∞, y → …
  5. As x → −∞, y → …
  6. The line y = … is an asymptote.

  Now sketch the graph.

### B. Sketch an exponential

Sketch each graph. Show the coordinates of any points where it crosses the axes, and the
equation of the asymptote.

- B1. y = 3eˣ − 6
- B2. y = 2eˣ + 5
- B3. y = 4e⁻ˣ + 1
- B4. y = 5e⁻ˣ − 2
- B5. y = −3e⁻ˣ + 6
- B6. y = 2e³ˣ + 4
- B7. y = 6e⁻²ˣ − 3
- B8. y = −e²ˣ + 5
- B9. y = −4e³ˣ − 1

### C. Sketch a logarithmic curve

Sketch each graph. Show the coordinates of any points where it crosses the axes, and the
equation of the asymptote.

- C1. y = ln (2x + 6)
- C2. y = ln (4x − 8)
- C3. y = ln (6 − 3x)
- C4. y = 3 ln (x + 2)
- C5. y = 2 ln (3x − 3)
- C6. y = −2 ln (4x − 6)
- C7. y = −ln (5 − x)

### D. Stretch (not in the book's exercise)

- D1. A curve has equation y = keˣ + a. Its asymptote is y = 2 and it passes through
  (0, 5). Find k and a.
- D2. A curve has equation y = k ln (x + b). Its asymptote is x = −4 and it passes
  through (−2, 3 ln 2). Find k and b.
- D3. For which values of a does the curve y = 2eˣ + a cross the x-axis?
- D4. Without sketching, decide whether each curve rises or falls from left to right:
  y = 5e⁻ˣ − 2, y = −e²ˣ + 5, y = −2 ln (4x − 6), y = ln (6 − 3x).

## Answers

In each answer, "falls" and "rises" describe the curve from left to right.

**A.** A1 −3; (0, −3); e²ˣ = 2, so x = ½ ln 2 ≈ 0.347; +∞; −6; y = −6.

**B.**

| | y-intercept | x-intercept | Asymptote | Shape |
|---|---|---|---|---|
| B1 | (0, −3) | x = ln 2 ≈ 0.693 | y = −6 | rises |
| B2 | (0, 7) | none | y = 5 | rises |
| B3 | (0, 5) | none | y = 1 | falls |
| B4 | (0, 3) | x = ln 2.5 ≈ 0.916 | y = −2 | falls |
| B5 | (0, 3) | x = −ln 2 ≈ −0.693 | y = 6 | rises towards the asymptote |
| B6 | (0, 6) | none | y = 4 | rises |
| B7 | (0, 3) | x = ½ ln 2 ≈ 0.347 | y = −3 | falls |
| B8 | (0, 4) | x = ½ ln 5 ≈ 0.805 | y = 5 | falls away from the asymptote |
| B9 | (0, −5) | none | y = −1 | falls |

**C.**

| | x-intercept | y-intercept | Asymptote | Exists for | Shape |
|---|---|---|---|---|---|
| C1 | (−2.5, 0) | (0, ln 6), about 1.79 | x = −3 | x > −3 | rises |
| C2 | (2.25, 0) | none | x = 2 | x > 2 | rises |
| C3 | (5/3, 0) | (0, ln 6) | x = 2 | x < 2 | falls |
| C4 | (−1, 0) | (0, 3 ln 2), about 2.08 | x = −2 | x > −2 | rises |
| C5 | (4/3, 0) | none | x = 1 | x > 1 | rises |
| C6 | (7/4, 0) | none | x = 1.5 | x > 1.5 | falls |
| C7 | (4, 0) | (0, −ln 5), about −1.61 | x = 5 | x < 5 | rises |

**D.** D1 a = 2 (the asymptote), then k + 2 = 5, so k = 3. D2 b = 4 (the asymptote is
where x + b = 0), then k ln 2 = 3 ln 2, so k = 3. D3 a < 0. D4 Falls, falls, falls,
falls. (A negative power, a negative multiplier, a negative multiplier, and a bracket
that shrinks as x grows.)

## Notes for building

- This section is planned for the graphs unit (`AM_5D` if chapter 5 becomes four units).
- The existing Sketch It task may fit: each curve is fixed by two intercepts and one
  asymptote. Check whether it can take a vertical asymptote before relying on it.
- The x-intercept is where students meet "no solution" again: B2, B3, B6 and B9 have
  none. A task should ask "does it cross the x-axis?" before asking where.
