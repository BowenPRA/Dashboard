# Add Maths 5.11 — The inverse of logarithmic and exponential functions

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.11, pages 121–122. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh problem set that covers every type, with answers. None of the
problems are the book's. Every answer was checked by script.

## Part 1 — The beats of the notes

1. **Link back (p. 121).** Inverses of one-one functions were covered in chapter 1. This
   section applies the same method to exponential and logarithmic functions.
2. **Worked example 17, first part.** The inverse of an exponential function of the
   form ke^(nx) + a, in three labelled steps: write it as y = …, swap x and y, rearrange
   to make y the subject (subtract, divide, take ln, divide). The domain of the inverse
   is stated: it is the range of the original function.
3. **Worked example 17, second part.** The inverse of a function of the form
   k ln (ax + b), by the same three steps (divide, write as a power of e, rearrange).
   Its inverse is defined for every real x.

## Part 2 — What the exercise asks

Exercise 5.11 is on pages 121–122: six questions.

| Type | Book question | What it asks | How it climbs |
|---|---|---|---|
| A. Inverse of an exponential | 1 (eight parts) | Find the inverse and state its domain | eˣ with a constant, then a multiplier, a multiple of x in the power, a negative power, then a constant minus an exponential |
| B. Inverse of a logarithmic function | 2 (six parts) | Find the inverse | A plain bracket, a multiplier, a multiple of x in the bracket, then a negative multiplier |
| C. Range, inverse, domain | 3 (four parts) | State the range; find the inverse; state its domain; find f⁻¹f(x) | One function |
| D. Composites and equations | 4, 5, 6 | Find fg(x) and gf(x) for an exponential f and a logarithmic g; solve an equation linking one function to the inverse of the other | The equations become a log equation, then an exponential one, then a hidden quadratic |

## Part 3 — Fresh problems in the same style

### A. Inverse of an exponential

Each function is defined for all real x. Find f⁻¹(x) and state its domain.

- A1. f(x) = eˣ + 7
- A2. f(x) = eˣ − 5
- A3. f(x) = 4eˣ + 3
- A4. f(x) = 2e³ˣ − 1
- A5. f(x) = 6e⁻²ˣ + 4
- A6. f(x) = 3 − eˣ
- A7. f(x) = 8 − 3e⁻⁴ˣ
- A8. f(x) = ½ e^(x/2) + 1

### B. Inverse of a logarithmic function

Find f⁻¹(x) for each function.

- B1. f(x) = ln (x + 4), x > −4
- B2. f(x) = ln (x − 6), x > 6
- B3. f(x) = 3 ln (x + 1), x > −1
- B4. f(x) = 2 ln (3x + 2), x > −⅔
- B5. f(x) = 4 ln (2x − 7), x > 7/2
- B6. f(x) = −2 ln (5x − 1), x > 1/5

### C. Range, inverse, domain

- C1. f(x) = e³ˣ − 2 for all real x.
  1. State the range of f.
  2. Find f⁻¹(x).
  3. State the domain of f⁻¹.
  4. Find f⁻¹f(x).
- C2. g(x) = 5 − 2e⁻ˣ for all real x.
  1. State the range of g.
  2. Find g⁻¹(x).
  3. State the domain of g⁻¹.
  4. Find gg⁻¹(x).

### D. Composites and equations

- D1. f(x) = eˣ for all real x, and g(x) = ln 3x for x > 0.
  1. Find fg(x) and gf(x).
  2. Solve g(x) = 2f⁻¹(x).
- D2. f(x) = e²ˣ for all real x, and g(x) = ln x for x > 0.
  1. Find fg(x) and gf(x).
  2. Solve f(x) = 3g⁻¹(x).
- D3. f(x) = e²ˣ for all real x, and g(x) = ln (x − 6) for x > 6.
  1. Find fg(x).
  2. Solve f(x) = g⁻¹(x).

### E. Stretch (not in the book's exercise)

- E1. f(x) = 2eˣ + 1 for all real x. Find f⁻¹(x). Sketch y = f(x) and y = f⁻¹(x) on the
  same axes, with the line they are reflections in. State the asymptote of each curve.
- E2. Explain why f(x) = e^(x²), defined for all real x, has no inverse. Suggest a
  domain for which it does, and find the inverse and its domain.

## Answers

**A.** A1 ln (x − 7), x > 7. A2 ln (x + 5), x > −5. A3 ln ((x − 3)/4), x > 3.
A4 ⅓ ln ((x + 1)/2), x > −1. A5 −½ ln ((x − 4)/6), x > 4. A6 ln (3 − x), x < 3.
A7 −¼ ln ((8 − x)/3), x < 8. A8 2 ln (2(x − 1)), x > 1.

**B.** B1 eˣ − 4. B2 eˣ + 6. B3 e^(x/3) − 1. B4 (e^(x/2) − 2)/3. B5 (e^(x/4) + 7)/2.
B6 (e^(−x/2) + 1)/5. Each inverse is defined for all real x.

**C.** C1 f(x) > −2; f⁻¹(x) = ⅓ ln (x + 2); x > −2; x. C2 g(x) < 5;
g⁻¹(x) = −ln ((5 − x)/2); x < 5; x.

**D.** D1 fg(x) = 3x; gf(x) = ln (3eˣ) = x + ln 3. f⁻¹(x) = ln x, so ln 3x = 2 ln x,
3x = x², and x = 3 (x must be positive). D2 fg(x) = x²; gf(x) = 2x. g⁻¹(x) = eˣ, so
e²ˣ = 3eˣ, eˣ = 3, x = ln 3. D3 fg(x) = (x − 6)². g⁻¹(x) = eˣ + 6, so e²ˣ − eˣ − 6 = 0,
eˣ = 3 (−2 rejected), x = ln 3.

**E.** E1 f⁻¹(x) = ln ((x − 1)/2), x > 1. The curves are reflections in y = x. The
asymptote of f is y = 1; the asymptote of f⁻¹ is x = 1. E2 It is not one-one: x and −x
give the same value. With domain x ≥ 0, f⁻¹(x) = √(ln x) for x ≥ 1.

## Notes for building

- This section was not in the original three-unit plan. It belongs with the graphs
  (`AM_5D` if chapter 5 becomes four units), because the domain of an inverse is read
  from the asymptote of the original curve.
- The three labelled steps (write as y, swap, rearrange) are a ready-made staged task.
  A fourth stage, "state the domain", is what question 1 adds.
- Types A6 and A7 are where signs go wrong: a constant minus an exponential gives a
  domain of the form x < a, not x > a.
- It depends on chapter 1 (functions). Check that the student has done composite and
  inverse functions before this unit opens.
