# Add Maths 5.4 — Solving logarithmic equations

Source section: Cambridge IGCSE and O Level Additional Mathematics coursebook (3rd
edition), section 5.4, pages 108–110. Read in the Cambridge GO reader on 2026-09-30.

Three parts: the beats of the notes in our own words, a map of the exercise's question
types, and a fresh problem set that covers every type, with answers. None of the
problems are the book's. Every answer was checked by script.

## Part 1 — The beats of the notes

1. **Where we are (p. 108).** Simple log equations were met in 5.2. These are harder.
2. **The one rule that matters.** Every root must be checked in the original equation.
   The algebra can produce values that make a log undefined.
3. **Worked example 9, first part.** A coefficient in front of one log and a single log
   on the other side. Steps: power law, then "equal logs mean equal numbers", expand,
   solve the quadratic. Each root is then tested. One makes a log of a negative number,
   so it is rejected.
4. **Worked example 9, second part (p. 109).** The unknown is the base. Power law,
   division law, convert to exponential form, solve x² = a number. The negative root is
   rejected because a base must be positive, and the other is checked by substitution.

## Part 2 — What the exercise asks

Exercise 5.4 is on pages 109–110: seven questions, the last two marked as challenge.

| Type | Book question | What it asks | How it climbs |
|---|---|---|---|
| A. Logs on both sides | 1 (four parts) | Combine, then equate the numbers | Sum, difference, a bracket, then a coefficient to move first |
| B. A constant on one side | 2 (six parts) | Combine, then convert to exponential form, or write the constant as a log | One bracket, then two, then a coefficient as well |
| C. Leading to a quadratic | 3 (eight parts) | Combine, solve, check both roots | Logs both sides, then a constant, then a coefficient; base 10 to finish |
| D. Unknown base | 4 (four parts) | Combine, convert, solve for the base | Difference, sum, coefficient, then a constant to move |
| E. Quadratic in a log | 5 (four parts) | Substitute for the log, solve, convert back | Plain first, then a log of a power that must be brought down |
| F. Simultaneous equations | 6 (six parts, challenge) | One equation in logs, the other a product, a power or a second log | Mixed |
| G. Linear equations in lg x and lg y | 7 (challenge) | Show a log equation can be rewritten, then solve a pair for lg x and lg y | Two parts |

## Part 3 — Fresh problems in the same style

Solve each equation. Check every root in the original equation.

### A. Logs on both sides

- A1. log₃ x + log₃ 5 = log₃ 35
- A2. log₂ 3x − log₂ 4 = log₂ 6
- A3. log₅ (x − 2) + log₅ 4 = 2 log₅ 6
- A4. log₇ (x + 1) = 2 log₇ 3 + log₇ 2
- A5. log₄ (2x + 1) − log₄ 3 = log₄ (x − 1)
- A6. 3 log₆ x = log₆ 64

### B. A constant on one side

- B1. log₂ x + log₂ 5 = 3
- B2. log₄ x + log₄ 8 = 3
- B3. lg (3x) − lg (x − 7) = 1
- B4. log₃ (x + 5) = 1 + log₃ (x − 1)
- B5. log₂ (3x + 2) = 3 + log₂ (x − 3)
- B6. log₄ (6x + 4) − log₄ (x − 1) = 2
- B7. lg (2x + 5) + 2 lg 3 = 1 + lg (3x − 1)

### C. Leading to a quadratic

- C1. log₂ x + log₂ (x − 2) = 3
- C2. log₅ (x + 1) + log₅ (x + 6) = log₅ 12x
- C3. 2 log₃ x − log₃ (x + 6) = 1
- C4. lg x + lg (x + 3) = 1
- C5. log₂ x + log₂ (2x − 7) = 2
- C6. 2 + 2 log₃ x = log₃ (26x + 3)
- C7. lg (x + 10) + lg 5x = 3
- C8. lg x + lg (x − 21) = 2
- C9. log₆ (x − 1) + log₆ (x + 4) = 2
- C10. log₃ (x − 4) = log₃ (2x − 5)

### D. Unknown base

- D1. logₓ 50 − logₓ 2 = 2
- D2. logₓ 9 + logₓ 3 = 3
- D3. logₓ 18 − 2 logₓ 3 = ½
- D4. logₓ 48 = 2 + logₓ 3
- D5. 2 logₓ 6 − logₓ 4 = 2
- D6. logₓ 5 + logₓ 25 = 3/2

### E. Quadratic in a log

- E1. (log₂ x)² − 5 log₂ x + 6 = 0
- E2. (log₃ x)² − log₃ (x²) = 3
- E3. (log₄ x)² + log₄ (x³) = 4
- E4. 2 (lg x)² − lg (x³) = 2
- E5. (log₂ x)² = log₂ (x⁴)

### F. Challenge-style: simultaneous equations

- F1. xy = 81 and logₓ y = 3
- F2. 3ˣ = 9ʸ and lg x + lg y = lg 18
- F3. log₂ (x + y) = 3 and log₂ x − log₂ y = log₂ 3
- F4. lg (xy) = 4 and lg (x/y) = 2
- F5. log₃ a = 2 log₃ b and log₃ (2a − 3b) = 3
- F6. 8^(xy) = 2^(3x + 12) and log₃ y − log₃ x = 1

### G. Challenge-style: equations in lg x and lg y

- G1. 1. Show that lg (x³y) = 11 can be written as 3 lg x + lg y = 11.
  2. Given also that lg (x/y²) = −1, find lg x and lg y. Hence find x and y.
- G2. log₂ (x²y) = 7 and log₂ (x/y) = −1. Find log₂ x and log₂ y, then x and y.

### H. Stretch (not in the book's exercise)

- H1. A student solves log₂ (x − 1) + log₂ (x + 1) = 3 and writes "x = 3 or x = −3".
  Which answer is wrong, and why?
- H2. Solve lg (x²) = (lg x)².

## Answers

**A.** A1 x = 7. A2 x = 8. A3 x = 11. A4 x = 17. A5 x = 4. A6 x = 4.

**B.** B1 x = 1.6. B2 x = 8. B3 x = 10. B4 x = 4. B5 x = 5.2. B6 x = 2.
B7 x = 55/12 (about 4.58).

**C.** C1 x = 4 (−2 rejected). C2 x = 2 or x = 3 (both valid). C3 x = 6 (−3 rejected).
C4 x = 2 (−5 rejected). C5 x = 4 (−½ rejected). C6 x = 3 (−1/9 rejected).
C7 x = 10 (−20 rejected). C8 x = 25 (−4 rejected). C9 x = 5 (−8 rejected).
C10 No solution: the algebra gives x = 1, which makes both logs undefined.

**D.** D1 x = 5. D2 x = 3. D3 x = 4. D4 x = 4. D5 x = 3. D6 x = 25. In each case the
negative root, where there is one, is rejected because a base must be positive.

**E.** E1 log₂ x = 2 or 3, so x = 4 or 8. E2 log₃ x = 3 or −1, so x = 27 or ⅓.
E3 log₄ x = 1 or −4, so x = 4 or 1/256. E4 lg x = 2 or −½, so x = 100 or 1/√10.
E5 log₂ x = 0 or 4, so x = 1 or 16. (Dividing through by log₂ x loses the root x = 1.)

**F.** F1 y = x³, so x⁴ = 81: x = 3, y = 27. F2 x = 2y and xy = 18: x = 6, y = 3.
F3 x + y = 8 and x = 3y: x = 6, y = 2. F4 lg x = 3, lg y = 1: x = 1000, y = 10.
F5 a = b² and 2a − 3b = 27: b = 9/2, a = 81/4 (b = −3 rejected).
F6 y = 3x and xy = x + 4: x = 4/3, y = 4 (x = −1 rejected).

**G.** G1 lg (x³y) = lg x³ + lg y = 3 lg x + lg y. The second equation is
lg x − 2 lg y = −1. Solving: lg x = 3, lg y = 2, so x = 1000, y = 100.
G2 2u + v = 7 and u − v = −1 give log₂ x = 2, log₂ y = 3, so x = 4, y = 8.

**H.** H1 x = −3 is wrong: it makes both logs of negative numbers. Only x = 3.
H2 2 lg x = (lg x)², so lg x = 0 or 2: x = 1 or x = 100.

## Notes for building

- This section is planned for `AM_5C`, with 5.6.
- The thread is "reject a root". It appears three ways here: a log of a negative (type
  C), a negative base (type D), and a lost root from dividing (E5). C2 and C10 are there
  so that the check is a real check: sometimes both roots survive, sometimes neither.
- A staged solver fits types A to D: combine, remove the logs, solve, then a final
  "check each root" stage.
